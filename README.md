# Zotero PDF 同步器

**Zotero PDF Syncer · macOS 桌面工具**

通过 macOS 软链接（Symbolic Link），将 Zotero 文献库中分散保存的本地 PDF 关联到指定文件夹，方便集中浏览、检索和阅读。程序不复制 PDF 数据，因此不会因创建链接而额外占用同等大小的 PDF 存储空间。

> **请注意**：本工具是**本机文件关联工具**，不是 Zotero 云同步、跨设备同步或 PDF 备份程序。软链接依赖原文件；原文件被移动或删除后，链接可能失效。通过软链接直接编辑 PDF，修改也可能写入 Zotero 中的原文件。

## 功能

- **手动更新**：立即扫描 Zotero 存储目录，并为新增的本地 PDF 建立软链接；已有有效链接自动跳过。
- **每天固定时间更新**：可自行设定每日同步的具体时间。
- **每隔 X 小时更新**：支持设置 1–24 小时的更新间隔，与每天固定时间模式二选一。
- **快速打开文件夹**：一键查看 Zotero PDF 原文件夹和同步目标文件夹。
- **本地后台运行**：使用 macOS 的 `launchd` 执行自动任务；关闭控制界面后，已配置的定时任务仍可运行。
- **双架构分发**：v1.3.0 的构建产物已检查包含 `arm64`（Apple Silicon）与 `x86_64`（Intel）架构。

## 安装与首次配置

1. 先安装并使用 [Zotero](https://www.zotero.org/)；确保需要关联的 PDF 已下载到本地。
2. 从 Releases 下载并打开 `.dmg`，将 **Zotero PDF 同步器.app** 复制到「应用程序」（Applications）文件夹。
3. 打开同步器，根据首次配置界面选择：
   - **PDF 来源文件夹**：通常为 `~/Zotero/storage`。如果修改过 Zotero 数据目录，请在 Zotero 的「设置 → 高级 → 文件和文件夹 → 显示数据目录」中核对实际位置。
   - **同步目标文件夹**：选择一个用于集中存放软链接的目录。建议优先选用当前用户拥有读写权限的目录。
4. 先点击 **「手动更新」**，确认 PDF 扫描数量、创建链接数量、失败数量及文件夹中的链接能否正常打开。
5. 需要自动更新时，打开 **「修改更新计划」**，选择「每天固定时间」或「每隔 X 小时（1–24）」并保存。

### 使用示例

Zotero 原始 PDF 位于：

```text
~/Zotero/storage/ABCD1234/论文A.pdf
~/Zotero/storage/EFGH5678/论文B.pdf
```

同步器会在所选目标目录中创建指向原 PDF 的软链接，供集中访问；原始 PDF 仍保留在 Zotero 存储目录中。

## 日常使用与常见问题

**问：同步器关闭后，还能自动更新吗？**

能。配置好的自动任务由 macOS `launchd` 负责运行，不要求应用窗口始终打开。睡眠、关机或未登录期间的触发可能延后或错过，不能保证严格按墙上时钟连续执行。

**问：Zotero 删除或移动了原文件，会怎样？**

链接可能失效。本工具不会替代原始文件备份，建议继续使用适合自己的 Zotero 数据备份方案。

**问：同步目标文件夹里的 PDF 是拷贝吗？**

不是。目标目录保存的是软链接。通过链接打开文件时访问的是源 PDF；对文件内容的修改可能影响原始 PDF。请勿把软链接文件夹当作独立备份。

**问：哪些附件会被扫描？**

默认针对所选 Zotero `storage` 目录中**实际存在于本机**的 PDF。尚未下载到本地的附件、目录外的外部链接附件不在默认扫描范围内。

**问：可以跨 Mac 传输 PDF 吗？**

不可以。软链接指向当前 Mac 的本地路径，不具备跨设备文件同步功能。

**问：提示没有权限或无法写入目标文件夹怎么办？**

macOS 对「文稿」「桌面」等位置可能实施额外访问控制。请在系统设置的隐私与安全性中检查相关文件访问权限，或选择当前用户可写的其他目标文件夹后重新测试；不要在未查明原因时给应用授予不必要的高权限。

## 安全与兼容性

- **平台**：macOS；v1.3.0 构建产物包含 Apple Silicon（ARM64）与 Intel（x86_64）两种架构。**最低兼容 macOS 版本尚未完成公开验证**。
- **运行条件**：本地已安装并配置 Zotero，且 PDF 实际存在于所选来源目录。
- **安全状态**：v1.3.0 分发包尚未完成 Apple Developer ID 签名、公证和独立设备的全面安装测试。互联网下载的应用可能受到 macOS Gatekeeper 检查。请先核验发布来源与文件完整性，再按照 macOS 提示处理；不建议为安装本工具全局关闭系统安全保护。
- **数据处理**：软链接操作在本地执行，本项目不提供文献云上传服务。
- **源码与许可**：本仓库当前用于发布二进制安装包及使用说明，**尚未公开软件源代码，亦未授予开源许可证**。仓库公开不等于软件已经开源。

## 校验下载文件

如果该版本的 Releases 附有 `SHA256SUMS.txt`，建议同时下载到安装包所在目录。在终端中进入该目录，并运行：

```bash
shasum -a 256 *.dmg
```

将输出的完整 SHA-256 值与 `SHA256SUMS.txt` 中**对应文件名**的记录比对。若校验不一致，请不要安装，应重新从官方 Release 下载。
