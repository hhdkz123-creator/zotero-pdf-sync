# Zotero PDF 同步器

面向 macOS 的 Zotero PDF 文件同步桌面工具，提供独立控制界面，用于管理 PDF 文件夹同步。

## 功能

- **手动更新**：通过桌面控制界面手动同步。
- **每天定时更新**：自定义每日更新时间。
- **间隔更新**：自定义每隔 1–24 小时运行一次同步。
- **快速访问文件夹**：一键查看原文件夹、同步文件夹。

## 下载与安装

前往 [Releases](../../releases/latest) 下载 `Zotero-PDF-Sync-v1.3.0-macOS.dmg`。打开 DMG，按照安装包内的实际提示完成安装，设置原文件夹与目标文件夹，并先测试“手动更新”。

## 文件完整性校验

同版本 Releases 附有 `SHA256SUMS.txt`。在放有安装包的目录运行：

```bash
shasum -a 256 Zotero-PDF-Sync-v1.3.0-macOS.dmg
```

将结果与 `SHA256SUMS.txt` 中的校验值对照。
